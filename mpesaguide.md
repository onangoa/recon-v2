# M-Pesa Integration Guide

This project uses the Safaricom Daraja API for M-Pesa integrations. The implementation is located in `lib/mpesa.ts` and managed via `lib/wallet-service.ts`.

## Environment Variables

Ensure the following variables are set in your `.env` file:

```env
# M-Pesa Credentials
MPESA_CONSUMER_KEY=your_key
MPESA_CONSUMER_SECRET=your_secret
MPESA_SHORTCODE=174379
MPESA_PASSKEY=bfb279f9aa9bdbcf158e97dd71a467cd2e0c893059b10f78e6b72ada1ed2c919
MPESA_CALLBACK_URL=https://your-domain.com/api/callbacks/mpesa

# Payout Credentials (B2C/B2B)
MPESA_B2C_SHORTCODE=your_b2c_shortcode
MPESA_INITIATOR_NAME=reconapi
MPESA_INITIATOR_PASSWORD=your_password
MPESA_CERT_PATH=./certificates/ProductionCertificate.cer
```

## Features Implemented

### 1. STK Push (Deposits)
Used to prompt users to enter their PIN on their mobile phones.
- **Service**: `initiateSTKPush(phoneNumber, amount, accountReference, description)`
- **Callback**: `/api/callbacks/mpesa/stk`

### 2. B2C Payouts (Send to Phone/Pochi)
Used to send money from the business to a customer's phone or Pochi la Biashara.
- **Service**: `initiateB2C(phoneNumber, amount, commandID, remarks, occasion)`
- **Callback**: `/api/callbacks/mpesa/payout-result`

### 3. B2B Payouts (Paybill/Till)
Used to pay suppliers via their Paybill or Buy Goods Till number.
- **Service**: `initiateB2B(receiverShortCode, amount, commandID, accountReference, remarks)`
- **Callback**: `/api/callbacks/mpesa/payout-result`

### 4. Transaction Status Query
Check the status of a specific M-Pesa transaction.
- **Service**: `checkTransactionStatus(transactionID)`

### 5. Account Balance
Query the current balance of the M-Pesa shortcode.
- **Service**: `checkAccountBalance()`

### 6. Reversal
Request a reversal for a transaction.
- **Service**: `initiateReversal(transactionID, amount, remarks)`

## Security Credential Generation

For B2C, B2B, and other sensitive endpoints, Safaricom requires a `SecurityCredential`. This is generated by encrypting the `Initiator Password` using a public key certificate provided by Safaricom.

The implementation in `lib/mpesa.ts` uses the Node.js `crypto` module to handle this:

```typescript
const generateSecurityCredential = (password: string) => {
  const cert = fs.readFileSync(MPESA_CERT_PATH, 'utf8');
  const buffer = Buffer.from(password);
  const encrypted = crypto.publicEncrypt(
    {
      key: cert,
      padding: crypto.constants.RSA_PKCS1_PADDING,
    },
    buffer
  );
  return encrypted.toString('base64');
};
```

## Deployment Notes

1. **Callback URLs**: Ensure your `MPESA_CALLBACK_URL` is accessible from the internet (Safaricom servers).
2. **Certificates**: Keep your `.cer` files secure and do not commit them to version control if they contain sensitive production data.
3. **Sandbox vs Production**: The base URL in `lib/mpesa.ts` defaults to sandbox. Update it to `api.safaricom.co.ke` for production.
